# NJ-LEND-002 DOBI Consumer Inquiry and Response Center aggregate request (draft)

Narrow request for non-PII complaint aggregates. Draft only. Not submitted by
this ticket.

## Why this request exists

`https://www.nj.gov/dobi/consumer.htm` describes how a consumer may inquire or
file a complaint through the Consumer Inquiry and Response Center (CIRC). The
page is an intake and contact directory. It does not publish mortgage-lender,
mortgage-broker, mortgage-servicer, or state-chartered-bank complaint
aggregates. No public count, category, or disposition table was acquired.

This ticket does not request consumer narratives or identities.

## Requested records

Annual aggregates, 2018 through the latest complete year, for:

- residential mortgage lenders
- residential mortgage brokers
- correspondent residential mortgage lenders
- mortgage servicers
- state-chartered banks and credit unions
- consumer lenders

Fields, if maintained:

- year
- legal entity name
- NMLS ID and/or NJ license / reference number
- license class
- complaint count
- official category
- disposition
- whether the matter was referred to enforcement

Statewide totals are acceptable if entity-level data is not releasable.

## Exclude

- consumer names
- complaint narratives
- account numbers, loan numbers, addresses
- any other personal information

## Semantics that must be preserved

A complaint is not a violation. Complaint volume is not a complaint score, not
a ranking, and not a Trust Score.

## Purpose

Internal coverage documentation only.

## Delivery preference

CSV/XLSX with field definitions and as-of date, or written confirmation that
no public aggregate series exists.

# NJ-LEND-001 DOBI public records request (draft)

Narrow request for current and historical Office of Consumer Finance licensee
records. Draft only. Not submitted by this ticket.

## Why this request exists

The public Banking Licensee Search at `https://www-dobi.nj.gov/DOBI_LicSearch/bnkSearch.jsp`
is a supported name-or-7-digit-reference lookup. The landing page states that
the list includes only actively licensed individuals and organizations, excludes
banking institutions, and directs residential mortgage lender / originator
lookups to NMLS Consumer Access. There is no documented bulk export. Automated
enumeration is not permitted. Absence from an active-only search does not prove
revocation, never-licensed status, or that a historical order is invalid.

## Requested records

For Office of Consumer Finance licensees, current and historical:

- DOBI reference number
- legal name
- DBA
- license type / class
- status
- initial date
- expiration date
- business address
- NMLS ID where the Department maintains it
- qualified individual where publicly releasable
- branch relationships
- status-change date

## Exclude

- personal home addresses
- personal email or telephone
- protected individual information
- insurance producer, carrier, market-conduct, or SERFF records
- full database dumps unrelated to OCF licensing

## Purpose

Identity resolution for respondents already named on official DOBI OCF
enforcement indexes. Not a public MLO directory and not a consumer ranking.

## Delivery preference

Delimited text or official spreadsheet with field definitions and as-of date.
